# `database` (Infrastructura de Date)

Conține definiția structurală a bazei de date relaționale pentru întregul ecosistem **GraciaRevive**.

## Responsabilități
* **Scheme SQL:** Scripturi `.sql` pentru crearea tabelelor aferente `auth-service` și `game-engine`.
* **Date Inițiale:** Popularea bazei de date cu datele statice necesare la prima instalare.
* **Performanță și Migrări:** Definirea indecșilor pentru optimizarea interogărilor și gestionarea scripturilor de migrare între versiuni.
